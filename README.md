# Physicos® | Jurerê Internacional

Site institucional de alta conversão e estética médica avançada para a clínica **Physicos Jurerê Internacional** em Florianópolis - SC.

## 📁 Estrutura do Projeto
- `index.html`: Página principal com catálogo interativo, galeria Instagram, simulador de protocolos e WhatsApp inteligente.
- `css/custom.css`: Estilos de alto padrão, fontes e efeitos visuais dourados e clean.
- `js/main.js`: Lógica do catálogo, modal de detalhes, simulador de protocolos e central de WhatsApp.
- `apresentacao_cliente.html`: Apresentação executiva para reunião com o cliente (com botão de exportar para PDF).
- `vercel.json`: Configuração de deploy instantâneo para testes no Vercel.
- `.htaccess`: Configuração de cache e segurança para a hospedagem DreamHost.
- `PROPOSTA_APRESENTACAO_CLIENTE.md`: Roteiro estratégico de apresentação e diagnóstico da clínica.
- `COMO_PUBLICAR_FILEZILLA_DREAMHOST.md`: Guia passo a passo de publicação no DreamHost via FileZilla.

## 🚀 Como testar no VS Code
1. Abra a pasta `physicos` no VS Code.
2. Dê dois cliques em `index.html` ou use a extensão Live Server.
3. Para publicar testes no Vercel, execute `vercel` no terminal.
